# Contribuir · Contributing

Ideas, preguntas y mejoras son bienvenidas por *issues* y *pull requests*.
*Ideas, questions, and improvements are welcome through issues and pull requests.*

- Nunca subas credenciales, claves de red ni tokens de Home Assistant. / Never commit credentials, network keys, or Home Assistant tokens.
- Al agregar datos, incluye unidades, fecha y versión del firmware. / When adding data, include units, date, and firmware version.
- Al cambiar el estado de un proyecto, actualiza su README y la ficha del sitio. / When a project's status changes, update its README and the site entry.
- Al contribuir aceptas publicar tu aporte bajo la licencia de la carpeta correspondiente. / By contributing you agree to release your work under the licence of the corresponding folder.
- Si integras un proyecto existente, sigue [`REUSING.md`](REUSING.md) y acredítalo. / If you integrate an existing project, follow [`REUSING.md`](REUSING.md) and credit it.
